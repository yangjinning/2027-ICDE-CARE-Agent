\subsection{Datasets and Tasks}
\label{sec:datasets}

We benchmark all methods on two public critical care electronic health record (EHR) databases harmonized under the YAIB schema~\cite{vandewater2024yaib}: MIMIC-IV (v3.1)~\cite{johnson2023mimic} (single-center, Beth Israel Deaconess Medical Center) for autonomous search and 5-fold in-center evaluation, and eICU-CRD~\cite{pollard2018eicu} (multi-center, $>200$ US hospitals) for zero-shot cross-center transfer. Each ICU stay provides $|\mathcal{C}|=52$ standardized clinical variables (4 static demographic and 48 hourly dynamic physiological and laboratory features). Following Section~\ref{sec:problem}, we cover five tasks spanning stay-level one-shot vs.\ hourly rolling prediction and classification vs.\ regression: in-hospital mortality from the first 24~h (Mortality24), hourly acute kidney injury (AKI) and sepsis (SEPSIS) onset detection within $[-6\text{ h}, +6\text{ h}]$, 24--48~h median serum creatinine prediction (Kidney Function), and hourly remaining ICU length of stay (LOS). Detailed cohort statistics and evaluation metrics are summarized in Table~\ref{tab:datasets}.

\subsection{Baselines}
\label{sec:baselines}

We compare CareAgent against twelve baselines spanning fixed clinical models, generalist coding and machine learning (ML) agents, and healthcare agents:
\begin{itemize}
    \item \textit{YAIB}~\cite{vandewater2024yaib}: Five fixed-architecture clinical ML benchmarks trained on identical splits: YAIB-LightGBM, YAIB-GRU, YAIB-LSTM, YAIB-TCN, and YAIB-Transformer.
    \item \textit{OpenHands}~\cite{wang2025openhands}: An open-source framework for generalist autonomous software-development agents that write, edit, and run code interactively within an isolated sandboxed workspace.
    \item \textit{AIDEML}~\cite{jiang2025aide}: An agentic ML framework that performs tree-structured exploration in code space via iterative drafting, debugging, and refinement.
    \item \textit{AIRA}~\cite{toledo2025aira}: An AI research agent for automated ML experimentation; we adopt its Monte Carlo Tree Search (MCTS) search strategy (denoted uniformly as AIRA in Table~\ref{tab:overall_performance}).
    \item \textit{AutoML-Agent}~\cite{trirat2025automlagent}: A multi-agent LLM framework for full-pipeline AutoML using retrieval-augmented planning across specialist sub-agents.
    \item \textit{FOREAGENT}~\cite{zheng2026foreagent}: A predictive ML-engineering agent using a predict-then-verify loop with execution priors to forecast candidate outcomes before running code.
    \item \textit{HealthFlow}~\cite{zhu2026healthflow}: A strategically self-evolving multi-agent framework for EHR analysis that coordinates meta-planning, execution, evaluation, and reflection into a persistent knowledge base.
    \item \textit{MedRSI}~\cite{wu2026medrsi}: A medical recursive self-improvement agent that turns diagnostic failures into new capabilities via clinical-cost-aware prioritization and cohort-validated registration.
\end{itemize}

\subsection{Implementation Details}
\label{sec:implementation}

\textit{Harness, LLM Backbone, and Budget.}
Our initial harness is OpenHands v1.53.0 (\texttt{openhands-sdk}/\texttt{openhands-tools} v1.53.0, Python 3.12). All agentic baselines and CareAgent use GLM-5.2 (ZhipuAI) with web search disabled. For $\mathcal{A}_{\text{exp}}$, we set the sampling temperature to 0.5, reasoning effort to \texttt{high}, and maximum output length to $65{,}536$ tokens (with \texttt{LLMSummarizingCondenser} at \texttt{medium} effort); for the stateless $\mathcal{A}_{\text{aud}}$, we set the temperature to 0.2 and maximum output length to $32{,}768$ tokens. For the Guideline Alignment Score ($\text{GAS}$), we fix $\tau_w=0.25$ and $\tau_{\text{act}}=0.01$. All experiments run on a server equipped with $8\times$ NVIDIA RTX PRO 6000 Blackwell Server Edition GPUs (96~GB VRAM each). Every agentic method shares a strict budget of $B=50$ submitted runs (\texttt{early\_stopping=False}); CareAgent devotes its first $N_0=5$ submissions to initializing five diverse seed models across heterogeneous model families.

\textit{Guardrails and Evaluation Protocol.}
Candidates execute in an isolated worker runtime (\texttt{seed=1}) with unified training caps (50 epochs with patience 3 for neural models, 100 boosting rounds for trees, and $1{,}000$ iterations for linear models) and verified GPU execution. Patient-disjoint splits, hidden test labels, \texttt{FitGuard} training-only checks, and causal hourly prefix streaming ($\tau \le t$) strictly prevent leakage. On MIMIC-IV, search runs on fold 0; the winning candidate is frozen and refitted across all 5 locked test folds (mean$_{\pm\text{std}}$). For MIMIC-IV $\rightarrow$ eICU, the frozen MIMIC-IV candidate is zero-shot refitted on the eICU-CRD training split (\texttt{r0f0}) without further search and evaluated on the locked test split.

\textit{In-Center Performance on MIMIC-IV.}
CareAgent achieves the best primary metric across all five clinical prediction tasks on MIMIC-IV, outperforming every fixed clinical benchmark and autonomous agent baseline. Specifically, on the highly imbalanced Sepsis task ($1.28\%$ prevalence), CareAgent achieves 0.1267 AUPRC and 0.8538 AUROC, surpassing the strongest baseline (AIRA at 0.1103 AUPRC) by $+14.9\%$ relative AUPRC and the strongest fixed YAIB baseline (YAIB-LightGBM at 0.0987) by $+28.4\%$. On Kidney Function, CareAgent achieves the lowest MAE of $0.2156\text{ mg/dL}$, reducing error by $15.4\%$ over YAIB-LightGBM ($0.2548\text{ mg/dL}$) and outperforming the runner-up FOREAGENT ($0.2194\text{ mg/dL}$). On AKI, CareAgent achieves the highest AUPRC of 0.7571 (and second-best AUROC of 0.9178), surpassing all YAIB baselines (best: YAIB-GRU at 0.7232 AUPRC) as well as MedRSI (0.7566 AUPRC) and AIRA (0.7560 AUPRC). On Mortality24 and LOS, CareAgent likewise ranks first on both primary metrics, achieving 0.4433 AUPRC (ahead of HealthFlow at 0.4416) and $34.1126\text{ h}$ MAE (ahead of FOREAGENT at $34.2353\text{ h}$ and YAIB-Transformer at $36.6800\text{ h}$).

By contrast, existing baselines exhibit pronounced task-to-task instability. Fixed YAIB models lag behind agent-discovered pipelines on four of the five tasks, particularly on Kidney Function and LOS where tailored temporal feature engineering is critical. General-purpose coding and AutoML agents struggle with acute-onset rolling tasks: OpenHands drops to 0.4566 AUPRC on AKI, while AutoML-Agent collapses to a degenerate predictor (0.0128 AUPRC, 0.5000 AUROC) on Sepsis under extreme class imbalance. Even strong domain-specific agents show sharp trade-offs: HealthFlow performs well on Mortality24 (0.4416 AUPRC) but degrades to 0.0766 AUPRC on Sepsis, whereas MedRSI is competitive on AKI (0.7566 AUPRC) but drops to 0.3796 AUPRC on Mortality24 and 0.0853 AUPRC on Sepsis.

\textit{Cross-Center Generalization (MIMIC-IV $\rightarrow$ eICU-CRD).}
The advantage of CareAgent becomes even more pronounced under zero-shot cross-center transfer to eICU-CRD, where models must remain robust across more than 200 distinct hospitals without re-searching or re-tuning. CareAgent achieves the best performance in five of the eight cross-center columns---Mortality24 AUPRC (0.3868), AKI AUPRC (0.7496), AKI AUROC (0.9145), Sepsis AUROC (0.7884), and Kidney Function MAE ($0.2634\text{ mg/dL}$)---and the second-best performance in two additional columns: Sepsis AUPRC (0.0601) and LOS MAE ($34.6974\text{ h}$, within $0.07\text{ h}$ of FOREAGENT's $34.6268\text{ h}$). Notably, while MedRSI is close to CareAgent in-center on MIMIC-IV AKI (0.7566 vs.\ 0.7571 AUPRC), its performance degrades noticeably upon transfer to eICU-CRD (0.7362 vs.\ 0.7496 AUPRC; 0.9105 vs.\ 0.9145 AUROC), demonstrating that clinically audited feature representations resist center-specific overfitting.
